# KJT Invest releases (newest version)

- **Linux computer:** [kjt-invest-linux.flatpak](kjt-invest-linux.flatpak) - download, double-click, press Install.
- **Linux phone (ARM):** [kjt-invest-linux-arm.flatpak](kjt-invest-linux-arm.flatpak)
- **Android:** [kjt-invest-android.apk](kjt-invest-android.apk)

`latest.json` tells the apps the newest version; they check it and offer the update themselves.
Every file's fingerprint (SHA-256) is in latest.json and is checked before anything is installed.
