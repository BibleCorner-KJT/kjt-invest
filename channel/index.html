KJT Finance

Private tracker for precious metals, real estate, cash and other assets. By Knowing Jesus Today.

Install on a computer (opens Software) Download for a computer (.flatpak file) Download for a Linux phone (ARM .flatpak file)

Double-click the downloaded file and press Install. After that, Software (GNOME Software) keeps KJT Finance up to date by itself. To remove it: Software › Installed › KJT Finance › Uninstall.

Open source (GPL-2.0-or-later): github.com/BibleCorner-KJT/kjt-invest. No accounts, no analytics, no tracking.
